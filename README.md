# javascript-calculator-precourse

## 애플리케이션 개요

- 입력한 문자열에서 숫자를 추출하여 모두 더하는 계산기

- 입력값: 구분자와 양수로 구성된 문자열

- 기본 구분자는 ","(쉼표), ":"(콜론)

- 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용

- 잘못된 값을 입력할 경우 "[ERROR]"로 시작하는 메시지와 함께 에러 발생시킨 후 애플리케이션 종료

## App.js 코드 구조

- fail, splitItems, validateItem, sumItems, App으로 구성

- fail(): 메시지와 함께 에러를 발생시키는 함수

- splitItems(): 입력받은 문자열을 구분자로 나누어 배열로 반환하는 함수

- validateItem(): 각 요소(item)가 "양수인 정수"인지 검사하는 함수

- sumItems(): 요소들의 합을 계산하는 함수

- App: 전체 실행 흐름을 제어하는 클래스
